# OttoMagic

the GPAL browser REST API executor, by Software Decisions, Inc. Part of the GPAL family: https://gpal.sditx.com/

A browser extension for Chrome, Edge and Firefox that lets GPAL, and the GPALRestAPI host, drive a real
signed-in browser profile through a REST API.

## This repository

This is the read-only public release mirror of OttoMagic version 1.0.0.0, taken from release commit `646ab48` of
the private OttoMatic browser extension repository. Development happens privately, and pull requests are not accepted here.
